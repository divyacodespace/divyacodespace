## 4. Enable the contribution snake animation

The snake graphic (`raw.githubusercontent.com/divyacodespace/divyacodespace/output/snake-dark.svg`)
is generated by a GitHub Action, not a static file. Steps:

1. `.github/workflows/snake.yml` is already included in this repo at the right path.
2. Push to `main`. The action runs on push and once daily, and commits the generated SVG to an `output` branch.
3. In your repo settings, confirm Actions have permission to push (Settings → Actions → General → Workflow permissions → "Read and write permissions").
4. The `<img>` tag in `README.md` already points at the `output` branch — no further changes needed once the branch exists.

## 5. A note on the embedded services

The footer quote used to call `quotes-github-readme.vercel.app`, a community API that's often
unreliable — it's now a local card (`assets/images/quote-card.svg`) with your real quote baked in,
so it always renders. The services still in use are lower-risk (widely used, actively maintained):

- `readme-typing-svg` — animated typing text
- `skillicons.dev` — clean SVG tech-stack icons
- `github-readme-stats`, `github-readme-streak-stats`, `github-readme-activity-graph`, `github-profile-trophy` — analytics widgets
- `komarev.com/ghpvc` — profile view counter
- `capsule-render` — the footer wave banner

All are configured with your palette (`bg=0B1120`, `primary=7C3AED`, `secondary=3B82F6`, `accent=06B6D4`,
`success=22C55E`, `text=F8FAFC`) via URL parameters, so they match the hand-built SVGs in `assets/`.
If any service is down, that one image will just fail to load — nothing else on the page depends on it.
